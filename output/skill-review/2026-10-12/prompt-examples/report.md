# 고급 활용법·간단 프롬프트 검토와 보완

## 검토 범위

`skill-creator` 기준으로 게임 기획 스킬, 참조 색인, 장별 자료, 용어·패턴·판단표와 README·고급 활용법을 대조했다. 21장별 42개 예시와 21개 후속 요청은 읽기 전용 독립 검토자가 대조했다. 원본 PDF 재감사가 아니라 이미 구성된 스킬·참조 자료에 맞는 활용 안내를 검토한 작업이다.

## 개선 사항

| 대상 | 발견한 문제·부족 | 최종 변경 |
|---|---|---|
| README | 짧은 요청이 주로 일반 설계·검토에 한정되고 결과 선택이 어려움 | 목적별 짧은 예시 8개와 기대 결과, 맥락·확정/미정·산출물 요청 틀 추가 |
| 첫 설계 예시 | 초심자가 많은 장 번호를 먼저 지정해야 함 | 참조 색인에서 필요한 장을 골라 읽도록 단순화 |
| A/B 안내 | A=설계·B=검토라는 설명과 실제 분석·비교 예시가 맞지 않음 | 제목·첫 요청을 보고 현재 목적에 맞게 선택하도록 안내 |
| 07장 기본 요청 | 일부 예외가 모든 기능의 필수 항목처럼 읽힘 | 해당 기능에 적용되는 예외 후보만 다루도록 한정 |
| 10장 기본 요청 | 변경 빈도만으로 안정적인 참조 데이터까지 배제할 여지 | 테이블·코드·전용 도구·개인 상태의 적합성 비교로 수정 |
| 15장 기본 요청 | 정적 표시에도 입력·저장 항목을 요구할 여지 | 정적 요소와 상호작용 요소에 해당되는 명세 구분 |
| 18장 기본 요청 | 파견 예외가 일반 기능 전체의 필수 테스트처럼 읽힘 | 기능에 해당되는 모집·편성 등의 반례만 요청 |
| 21장 기본 요청 | 필요한 정렬·동점 기준을 확인하는 항목이 약함 | 해당되는 정렬·동점 기준 보강 |
| 08·18·20장 후속 요청 | A의 산출물만 가정하여 B 선택 뒤 엉뚱한 범위로 이동할 수 있음 | 현재 다룬 정책·문서·단계에 이어지도록 수정 |
| 공통 활용 | 자료 선택·동일 조건 비교·부분 변경·QA를 직접 요청하는 안내 부족 | 목적별 공통 프롬프트 4개와 선택 표·기대 결과 추가 |
| 안내와 탐색 | 작업 순서·예시 행 수가 책의 필수 규격처럼 읽힐 여지 | 예시 순서임을 명시하고 필요한 단계만 사용하도록 안내, 상단 바로가기 보강 |

각 복사형 예시의 미정·근거 구분 문구는 독립 사용에 필요하므로 유지했다. 장별 예시를 추가로 늘리지 않았으며 새 공통 프롬프트는 스킬 기반의 응용 예시라고 명시했다. 신규 QA 예시의 모호한 ‘미정 참조’는 독립 최종 검토 후 ‘누락되었거나 잘못된 참조’로 명확히 했다.

## 보존한 범위

- 게임 기획 스킬과 참조 자료 28개 파일은 수정하지 않았다.
- 21장별 고급 예시 42개, 후속 요청 21개, 연계 시나리오 3개와 장 앵커를 유지했다.
- 변경 문서는 루트 README, 고급 활용법, 가이드 홈 3개다.
- 변환기를 사용자 문서나 기본 사용 의존성에 다시 추가하지 않았다.
- 기존 검수 기록은 당시 검증 범위의 결과로 유지하고, 이번 결과는 별도 기록했다.

## 검증 결과

- 문서·스킬 자료·기존 참조 검수 보고서 35개에서 로컬 링크/앵커 **376개**, 깨진 링크 **0개**.
- 기존 장별 고급 예시 **42개**, 후속 요청 **21개**, 시나리오 **3개**와 장 앵커 유지. 공통 예시 **4개** 추가로 고급 가이드 코드 블록은 **73개**.
- 게임 기획 스킬 **28개 파일의 SHA256**이 검토 시작 전과 동일. 스킬 형식 검사 통과.
- 새 비교·QA 프롬프트를 문서에서 직접 추출해 독립 평가 에이전트가 수행했다. QA 입력에는 가상 규칙·데이터·UI 명세만 추가했고, 기존 감사 결과·원본 PDF·외부 검색은 제공하지 않았다.

| 사용 테스트 | 최초 판정 | 보완과 최종 확인 |
|---|---|---|
| 동일 조건의 자동 지급/직접 수령 비교 | 통과 | 보상 조건을 유지하고 조건부 추천·미정 정책·효과의 불확실성을 보존 |
| 규칙·데이터·UI QA 검토 | 부분 통과 | 확정된 중복 반영 금지와 미정 응답 정책을 기대 저장 상태에서 더 분명히 분리하도록 요청 보강. 같은 평가 에이전트가 최신 요청으로 답변을 재작성한 뒤 해당 기준 통과 |

후속 QA 확인은 **새 독립 세션에서 다시 실행한 테스트가 아니다.** 최초 입력·답변·자료 목록은 `behavior/initial/`, 최신 산출물은 `behavior/`에 보존했다. 최종 답변의 근거 파일 링크 7개가 실제 읽은 경로에 존재함을 확인했다. 읽기 목록의 임시 입력 경로는 당시 읽은 원본 경로이며 입력 사본을 함께 보존했다.

## 한계

전체 프롬프트를 모든 모델·호스트에서 실행하지 않았다. 원문 PDF의 모든 문장·도판을 새로 검증하거나 실제 게임·앱을 실행하는 작업은 수행하지 않았다. 문서의 QA 예시는 설계된 검토 시나리오이며 실제 게임 테스트 결과가 아니다.
