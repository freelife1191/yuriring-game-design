보유량 **12개는 확정**, **기본 수량은 미정**으로 둡니다. 아래는 16장의 스테퍼 설계 원칙과 7장의 예외 처리 원칙을 적용한 **제안 명세**입니다. 책 사례의 기본값을 그대로 채택하지 않습니다.

**입력 규칙**

| 항목 | 명세 |
|---|---|
| 목적 | 아이템 사용 수량 선택 |
| 허용 범위 | 정수 **1~12** — 최소 수량 1 가정 |
| 변경 단위 | `−` / `+` 한 번에 1개 |
| 기본 수량 | **미정**. 최초 진입 수량·버튼 상태는 기본값 결정 후 확정 |
| 직접 입력 | 지원하는 것으로 가정. 아래 오류 정책 적용 |
| 반영 시점 | 수량 조절은 선택값만 변경. 사용 확정 시 실제 보유량 차감 |
| 재진입·저장 | 이전 선택값 복원 여부는 미정 |

**수량별 상태**

`q`는 검증을 통과한 선택 수량입니다.

| 상태 | 조건 | `−` | `+` | 사용 확정 |
|---|---|---|---|---|
| 최솟값 | `q=1` | 비활성 | 활성 | 가능 |
| 중간값 | `q=2~11` | 활성 | 활성 | 가능 |
| 최댓값 | `q=12` | 활성 | 비활성 | 가능 |
| 입력 중 | 직접 입력을 편집 중 | 비활성 | 비활성 | 불가 |
| 처리 중 | 사용 요청 후 결과 대기 | 비활성 | 비활성 | 비활성·중복 요청 차단 |
| 사용 불가 | 최신 보유량이 0 | 비활성 | 비활성 | 불가 |

경계에서 비활성 버튼을 눌러도 수량은 변하지 않으며 오류 알림도 띄우지 않습니다. 연속 클릭에도 매번 범위를 검사합니다. 길게 누르기 반복 입력은 지원 여부와 반복 간격을 별도로 결정합니다.

버튼은 **기본·눌림·비활성**을 구분합니다. 키보드 지원 시 **포커스**, 마우스 지원 시 **호버**를 추가하며, 비활성 상태는 눌림 동작을 수행하지 않습니다.

**직접 입력 오류와 보정 제안**

편집 중에는 입력 문자열을 유지하고, **포커스 이탈 또는 Enter**에서 검증합니다. 보정은 사용 실행을 뜻하지 않습니다.

| 입력·상황 | 처리 결과 | 안내 문구 예시 |
|---|---|---|
| 빈 값 | 직전 유효 수량으로 복원 | “수량을 입력해 주세요.” |
| 문자·소수·해석 불가 값 | 직전 유효 수량으로 복원 | “정수로 입력해 주세요.” |
| 0 또는 음수 정수 | 1로 보정 | “최소 1개부터 선택할 수 있어요.” |
| 12 초과 정수 | 12로 보정 | “보유 수량은 12개예요.” |
| 1~12 정수 | 해당 수량 적용·오류 해제 | 없음 |

오류는 수량 영역 가까이에 표시하고 **보정된 값도 함께 보여 줍니다**. 기본 수량이 미정이므로, 직전 유효 수량이 없는 최초 입력 실패의 복원값도 아직 확정할 수 없습니다.

**보유량 변경·실행 오류**

| 상황 | 처리 |
|---|---|
| 선택 중 보유량이 감소하고 `q`가 새 보유량을 초과 | 새 보유량으로 보정하고 변경 이유 안내. 자동 사용하지 않음 |
| 보유량이 0이 됨 | 선택값을 유효하지 않은 상태로 전환하고 “사용 가능한 아이템이 없어요.” 표시 |
| 사용 확정 시 수량 부족 | 실행 직전 최신 보유량 재검증. 사용·차감 없이 수량 갱신 및 안내 |
| 서버가 사용 실패를 확정 | 보유량 차감 없이 선택값 유지. 현재 조건을 재검증해 재시도 허용 |
| 응답 지연·결과 확인 불가 | 결과 확인 중 상태 유지. 처리 결과 확인 전 재요청 차단 |

확정이 필요한 항목은 **기본 수량, 최소 수량 1의 채택, 직접 입력 지원, 재진입 복원 정책, 길게 누르기 지원**입니다. 경계 검증 기준은 `1에서 − 불가`, `11에서 + → 12`, `12에서 + 불가`, `13 입력 → 12 보정`입니다.
