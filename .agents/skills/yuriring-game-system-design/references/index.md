# 참조 자료 색인

이 색인은 **스킬의 탐색을 위한 재구성**이다. 책의 새로운 장이나 저자의 별도 프레임워크가 아니다. 구체적인 질문에 맞는 장과 보조 자료를 선택하며, 원문 근거·쪽 범위는 각 장과 [source.json](../source.json)에서 확인한다.

## 어떤 자료를 읽을까?

| 필요한 것 | 읽을 자료 | 사용 방식 |
|---|---|---|
| 핵심 원칙·전체 장 목록 | [SKILL.md](../SKILL.md) | 요청 범위를 잡는다. |
| 개념·설계 절차·사례·예외 | 아래 색인에서 선택한 장 | 답변 전에 해당 장을 읽는다. 관련 장은 필요한 범위에서 연결한다. |
| 용어의 짧은 정의 | [glossary.md](../glossary.md) | 의미를 확인한 뒤 설명이 더 필요하면 해당 장을 읽는다. |
| 여러 장을 적용하는 작성 양식 | [patterns.md](../patterns.md) | 의도·기능·규칙·데이터·UI 양식을 고른다. 데이터의 행·중복 범위와 QA의 필수·조건부 결과도 점검한다. |
| 빠른 판단과 누락 점검 | [cheatsheet.md](../cheatsheet.md) | 초안을 점검하고 문제가 있는 영역의 장으로 돌아간다. |
| 원본·쪽 규약·검수 한계 | [source.json](../source.json) | 인용과 검증 범위를 확인한다. 검수 기록은 원문 전체의 정확성 보증이 아니다. |

## 자료를 적용할 때의 경계

- 장 파일은 **개념·절차·판단 규칙·선별한 사례를 합성한 자료**다. 모든 소절·표·스크린샷의 복제본은 아니다. 장에 없는 정확한 열 이름·수치·도식이 필요하면 확인할 원본 쪽을 안내한다.
- 원문 사례 재구성과 새 적용 예시는 구별한다. 책의 수치·조건을 서비스 기본값으로 옮기지 않는다. 미정 정책은 선택지와 영향으로 남긴다.
- UI 요소의 명세 항목은 해당 기능과 입력 환경에 맞게 적용한다. 정적 제목·설명에 입력·저장 조건을 강제하지 않는다.
- 책의 모호한 서술이나 확인하지 못한 시각 정보는 그대로 한계로 표시한다. 다른 장이나 일반 지식으로 채웠다면 책의 직접 설명처럼 인용하지 않는다.
- 답변에 자료의 파일 링크를 제공할 때는 실제로 읽은 경로를 사용한다.
